WEB DEVELOPMENT POE

Name: The Daily Grind Café 
History: This café was founded in 2024 by two specialty coffee enthusiasts who wanted to bring sustainably sourced, organic coffee to the local community.
Mission Statement: Our mission is to serve high quality, ethically sourced coffee and house-made pastries while fostering a welcoming community space.
Vision Statement: Our vision is to become the region’s leading zero-waste café and expand to three new locations within five years.
Target Audience: Our target audience is our local university students, remote freelancers aged 18-35, and neighbourhood residents who value premium, sustainable food choices.

2.	Website goals and objective 
•	Specific goals- Increase foot traffic by displaying a live, up-to-date seasonal menu. Streamline morning rushes by allowing customers to pre-order food and drinks online for pickup. Build customer loyalty by offering a digital rewards program signup. 
•	Key Performance Indicators (KPIs)- Process 50 online pickup orders per day within the first three months. Drive 500 unique local website visitors every week. Secure 200 new digital loyalty program registrations via the website monthly.

3.	Current Website Analysis
•	Analysis-The Daily Grind Café is a brand-new business and currently does not have an existing online presence.
•	Focus- Since there is no current site to analyse, all resources will be entirely dedicated to designing and launching this new, modern platform from scratch. 

4.	Proposed Website Features and Functionality
•	Essential Pages:
o	Homepage: High-quality photos of the café, current promotions, and a direct button to order online.
o	About Us: The story of the founders, details on the organic coffee farms, and sustainability values
o	Menu: An interactive, categorised menu showcasing drinks, pastries, and dietary/allergen filters (e.g., vegan, gluten-free).
o	Contact us: Operating hours, interactive Google Map Location, telephone number, and an embedded email contact form.

•	Desired Functionality
o	An e-commerce mobile-responsive shopping cart for the click-and-collect pickup system.
o	An integrated secure payment system (accepting credit cards, Apple Pay, and Google Pay).

5.	Design and User Experience
•	Design Aesthetic: Modern, minimalist, and warm, emphasizing cosy community vibes and natural elements.
•	Colour Scheme: Forest green(sustainability), warm cream (neutral background), and deep espresso brown (text and accents).
•	Layout and Design: Clean grid system with generous white space, large food photography, and prominent “Order Now” action buttons.
•	User Experience: A persistent navigation bar at the top of all pages for seamless browsing, single-click checkout for returning users, and an entirely mobile-optimized interface for customers ordering on the go.
•	Low-Fidelity Wireframe Plan: 
o	Header: Café logo on the far left, middle navigation links (Menu, About, Contact), and a high contrast “Order Now” button on the far right. 
o	Hero Section: A large, full-width banner image of the café interior with a centred headline (“Sustainably Sourced, Locally Brewed”) and prominent “View Menu” button.
o	Main Body Content: A 3-column grid directly below the fold displaying “Seasonal Favourites” with large square image placeholders, item titles, prices, and “Add to Cart” buttons.
o	Footer: A 3-section layout containing operating hours on the left, social media icons and map links in the center, and a newsletter email signup box on the right.

6.	Technical Requirements
•	Domain Name: ://thedailygrindcafe.com (secured via a registrar like a Namecheap). 
•	Web Hosting: A reliable cloud hosting provider with an integrated SSL certificate for secure online payments, automated daily backups, and at least 99.99% uptime. 
•	Languages and Frameworks:
o	Front-End: Semantic HTML5 for structural layout, CSS (utilizing the Tailwind CSS framework for fast, responsive styling), and JavaScript for interactive menu filters and cart updates.
o	Back-End and Database: Node.js with the Express framework to handle secure online ordering, paired with MongoDB to store customer accounts and menu date. 

7.	Timeline and Milestones
• Phase 1: Project Initiation & Planning (Week 1): Finalize the website sitemap, gather digital assets (café logos, initial menu items), and establish the project's technical architecture.
• Phase 2: UI/UX Wireframing & Design Approval (Week 2): Create and iterate on the low-fidelity and high-fidelity layouts, culminating in a design freeze milestone before coding begins.
• Phase 3: Core Front-End & Back-End Development (Weeks 3–4): Build out the user interface pages using HTML/CSS and set up the back-end servers, database schemas, and secure payment processing.
•	Phase 4: Testing & Content Integration (Week 5): Input final food descriptions and pricing, run cross-browser compatibility checks (Safari, Chrome, Edge), and execute mobile performance optimization.
•	Phase 5: Final Review & Deployment (Week 6): Conduct final end-to-end user acceptance testing for online orders, connect the live domain name, and deploy the website to production for public use.
